# PotteryVolumeCalculator moved to MorphPot

[**MorphPot**](https://github.com/kotdijian/MorphPot), the pottery analysis project in ArchMorph, is the maintained home for the voxel, section and drawing capacity workflows and related pottery tools. Please use MorphPot for new work and issue reports.

- [Capacity guide in English](https://github.com/kotdijian/MorphPot/blob/main/docs/capacity/README_EN.md) · [日本語](https://github.com/kotdijian/MorphPot/blob/main/docs/capacity/README.md)
- [AOM posture comparison](https://github.com/kotdijian/MorphPot/blob/main/docs/capacity/README_EN.md#compare-postures-exported-by-aom)

Run `python MorphPot.py volume` from the MorphPot checkout. The standalone `python vessel_voxel_volume.py` is also available there. This repository retains the old sources, example data and validation files for reproducibility. See the [last pre-migration snapshot](https://github.com/kotdijian/PotteryVolumeCalculator/blob/93fbdbad24f22c38423d9e1b4780622b2ef8ccab/README_EN.md) for its original instructions.
