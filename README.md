# PotteryVolumeCalculator — MorphPotへ移管

土器の容量計算と関連ツールは、ArchMorphの土器解析プロジェクト **[MorphPot](https://github.com/kotdijian/MorphPot)** で保守します。新しい利用・不具合報告・開発はMorphPotへお願いします。

- [容量計算ガイド（日本語）](https://github.com/kotdijian/MorphPot/blob/main/docs/capacity/README.md) / [English](https://github.com/kotdijian/MorphPot/blob/main/docs/capacity/README_EN.md)
- <a id="aom-pose-comparison"></a>[AOMの姿勢別容量比較](https://github.com/kotdijian/MorphPot/blob/main/docs/capacity/README.md#aom-pose-comparison)
- [放射断面と断面法容量](https://github.com/kotdijian/MorphPot/blob/main/README.md#radial-sections-guide)・[表面痕跡解析](https://github.com/kotdijian/MorphPot/blob/main/README.md#surface-trace)

MorphPotでは `python MorphPot.py volume` を使います。旧コマンド `python vessel_voxel_volume.py` もMorphPot内で引き続き使用できます。断面・実測図容量・破片境界の入口は移管先のREADMEとガイドを参照してください。

このリポジトリは過去の計算を再現できるように履歴とサンプルを保持します。[移管前の最終スナップショットと旧README](https://github.com/kotdijian/PotteryVolumeCalculator/blob/93fbdbad24f22c38423d9e1b4780622b2ef8ccab/README.md)。
